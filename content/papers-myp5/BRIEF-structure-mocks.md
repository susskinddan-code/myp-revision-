# Brief: eAssessment-style "Structure Mock" papers (MYP 5)

Goal: full-length, timed, exam-realistic papers that mirror the real MYP on-screen eAssessment structure (reference only; never copy any real IB paper, school mock, or sample paper). Everything must be ORIGINAL: new stimuli, data, texts, numbers, contexts.

## File format
One JSON file per paper in content/papers-myp5/, named `NN-<subject>-structure-mock-<a|b>.json` (NN given in your assignment). Content is an array with ONE paper:
{ "subject": "<slug>", "grade": 5, "format": "structured-mock",
  "title": "<Subject name> MYP 5 eAssessment Structure Mock <A|B> (<N> tasks, <M> marks)",   // N tasks = number of questions in file, M = total marks; must match exactly
  "criterion": null,
  "questions": [ { "position": 1, "marks": n, "criterion": "A|B|C|D", "content": "...", "mark_scheme": "..." } ... ] }
Validate with: cd /home/claude/myp-revision- && node scripts/papers-to-sql.mjs content/papers-myp5 > /dev/null   (ignore INVALID lines for files that are not yours).
Rules enforced by the validator: 5-10 questions per file; position = 1..n; total marks 60-130; each question <= 40 marks; content must contain "(n marks)" text; the mark scheme must contain "[1]" style award markers whose numbers SUM EXACTLY to `marks`; criterion single letter A-D (the criterion with most marks in that task); never write a 1-7 / "1 to 7" / "out of 7" range; never write A-level / Diploma Programme / IB DP / HL / SL.

## Question content conventions (copy exactly)
- Begin `content` with a header line `[[Q 3 | A 5 | C 2]]` = task label then per-criterion marks (Q number may have the task number only). Then the stimulus and the parts.
- Each task: a short real-world context/stimulus, then lettered parts (a), (b)... each ending with its marks e.g. "(2 marks)", using IB command terms in the real style: State, Identify, Describe, Outline, Explain, Calculate, Determine, Show that, Verify, Justify, Evaluate, Discuss, Compare and contrast, Design, Formulate, Suggest, Analyse, Interpret. End the question with "Total for Question n: m marks".
- Questions are plain text only (no images, markdown, or tables). Describe diagrams, graphs and photographs in words ("Diagram not to scale. [Description: ...]") with all data given as text lists such as "Year: 2010, 2015, 2020 / Value: 4, 7, 11". Data must be consistent with the questions and mark scheme.
- Mark schemes: per part, list the creditworthy answers with [1] markers, accept-alternatives, and for extended writing/analysis tasks give level descriptors per criterion with indicative content. Marks per criterion must be allocated per the header. Worked solutions in maths must show method marks. Every number verified in python3 before writing. Every fact must be correct for MYP level.
- Tasks must progress easy -> hard within the paper. Mix: short recall/apply tasks first, then data/investigation tasks, then a long extended task (design/evaluate/investigate/write) worth 10-35 marks.
- Interpretation: MYP criteria use Levels 1-8 per criterion; the paper itself shows only marks.
- Real-feel: include at least one "Show that ... " style, one multi-step application with real-world context, and one task needing a decision justified with evidence. Avoid trivia and slop; every question must test something a real examiner would.
- Paper A and Paper B for a subject must cover different topics/contexts (no repeated questions).

## Subject formats (target total marks in parentheses)
- Sciences (Physics / Chemistry / Biology / Integrated Science / Environmental Systems), 2 h: criteria A Knowing and understanding, B Inquiring and designing, C Processing and evaluating, D Reflecting on impacts of science. 7-8 tasks, 70-80 marks: short A tasks (stimulus + 4-6 parts), a task on an experiment design (B: research question, hypothesis, variables, method, safety), a data processing task (C: calculate, graph description, trend, anomaly, conclusion, evaluate method), a task on an impacts/ethics passage (D: benefits/risks, factors: moral, ethical, social, economic, political, cultural, environmental), plus one extended synthesis task. Use topics from the eAssessment topic lists in .lovable/plan/eassessment-topic-lists-sciences-humanities.md and maths-eassessment-format-and-topics.md.
- Individuals and Societies (History / Geography / Economics), 2 h: criteria A Knowing and understanding, B Investigating, C Communicating, D Thinking critically. Source-based: 3-4 sources (written, data table described in text, map/graph described, cartoon described) invented for this paper; questions use source skills (origin/purpose/value/limitation, compare sources, evaluate a claim), a data/stat task, and a 10-12 mark extended-response with a given conceptual/global-context link. 70-90 marks.
- Mathematics (Standard / Extended), 2 h, criteria A Knowing and understanding, B Investigating patterns, C Communicating, D Applying mathematics in real-life contexts; Task style per Dan's notes: 6-10 tasks; short tasks (7-10 marks), a long real-life task (~20 marks), an investigation (~25-35 marks). Per-part criterion tags. Target 80-100 marks. Extended includes logarithms, bounds, rational/trig graphs, more complex functions. Cover topics from the Maths topic list in .lovable/plan/.
- Language and Literature (English/French/Spanish), 2 h: Task 1 analysis of a text and a multimodal text (criteria A and B, with a compare-and-contrast), Task 2 literary writing (C and D), Task 3 non-literary writing (B, C, D) with a global context. Provide the texts in full in the question (original texts you write; for French/Spanish write them in that language, with questions in the target language where the real exam would, and mark schemes in English with target-language accuracy). 80 marks.
- Language Acquisition (French/Spanish/Mandarin ab initio, Phase 1-2 "Emergent"): criteria A Listening (transcripts of audio given as text, marked "[Audio transcript - read twice]"), B Reading, D Writing. 4-6 tasks, 60-70 marks: listening comprehension with short answers, reading comprehension of authentic-style short texts, vocabulary/grammar in context, a writing task of 60-90 words on units: identity and culture; education and work; the world we live in; local area, travel, tourism; technology and media. Questions mostly in English with target-language texts; Mandarin in simplified characters with pinyin. Language must be native-quality correct.
- Interdisciplinary Learning, 2 h: criteria A Disciplinary grounding, B Synthesizing, C Communicating, D Reflecting. Given a theme and 5-6 invented sources from different disciplines (an article, a data table, an infographic described in words, an interview extract, a short scientific note, a policy statement), tasks: identify the disciplines, explain connections, evaluate sources, synthesize a solution or product, reflect on the process. 60-80 marks.
